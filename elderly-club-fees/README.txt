ระบบบันทึกค่าสมาชิกชมรมผู้สูงอายุ (เวอร์ชัน 2)
==============================================

วิธีใช้งาน
1. แตกไฟล์ zip แล้วดับเบิลคลิก index.html (เปิดด้วย Chrome / Edge / Safari)
2. ครั้งแรกจะให้ตั้งรหัสผ่านสำหรับอีเมล ppinn474@gmail.com (อย่างน้อย 6 ตัวอักษร)
3. แท็บ "สมาชิก" ใช้กรอกข้อมูล (ชื่อ นามสกุล วันที่สมัคร วันที่ลงใบเสร็จ สถานะสมาชิก ค่าสมาชิก)
4. แท็บ "ตรวจสอบการชำระเงิน" เลือกปี (พ.ศ.) แล้วติ๊ก ✓ / ✗ พิมพ์รายงานและใบเสร็จ
5. แท็บ "สรุปรายเดือน" ยอดเก็บแต่ละเดือนของปีที่เลือก เทียบเดือนก่อน สถานะสมาชิก และพิมพ์ไปใช้ในที่ประชุม
6. แท็บ "ตั้งค่า / สำรองข้อมูล" ตั้งชื่อชมรม สำรอง/นำเข้าข้อมูล เปลี่ยนรหัสผ่าน ดูประวัติการใช้งาน

เพิ่มเติม (เวอร์ชัน 2.1)
- ติ๊กชำระหลายคนพร้อมกัน: ติ๊กช่องหน้ารายชื่อ แล้วกด "ติ๊กชำระที่เลือก" (เลือกวันที่ชำระได้)
- เรียงตามลำดับที่ / ชื่อ / บ้านเลขที่ และแบ่งหน้าทีละ 25 รายการ (พิมพ์รายงานจะพิมพ์ครบทุกคน)
- ใบเสร็จมียอดเงินเป็นตัวอักษรไทย  - ปุ่ม ก- / ก+ ปรับขนาดตัวอักษร
- หน้าจอแคบจะแสดงรายการเป็นการ์ด

สำคัญ
- ข้อมูลเก็บในเบราว์เซอร์ของเครื่องนี้เท่านั้น ควรกด "สำรองข้อมูลทั้งหมด (.json)" เป็นประจำ
- ถ้าลืมรหัสผ่าน การรีเซ็ตจะลบข้อมูลในเครื่อง แต่นำเข้าไฟล์สำรองกลับได้หลังตั้งรหัสผ่านใหม่
- การล็อกอินเป็นการล็อกหน้าจอฝั่งเบราว์เซอร์ ไม่ใช่ระบบความปลอดภัยระดับเซิร์ฟเวอร์
- ประวัติการใช้งานและเลขที่ใบเสร็จอยู่ในไฟล์สำรองด้วย
